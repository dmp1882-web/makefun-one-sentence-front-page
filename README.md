# One Sentence, One Front Page

make.fun bounty `u-brisk-kestrel-93-one-sentence-one-front-page-0db596eb` (program/v1).

Front-page headline for 23 November 2026: the COP31 climate talks in Turkey ended with no deal, the longest UN climate conference in history.

## Entry

```
COP31 collapses in Turkey with no climate deal after the longest talks in UN history.
```

## Program

`main.py` (Python 3.13, standard library only) writes the entry text to
`/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` stands in for `/output` outside
the grader). It is deterministic: the same bytes on every run.
